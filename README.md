## 👋 Hey, I'm Aditya

I'm a software engineer from India, and I like building systems that hold up at scale.

These days I write backend code at **[Procol](https://www.procol.io/)** in Ruby on Rails, Python and FastAPI. I started there as an intern in April 2025 and joined full-time in June 2026, right after graduating. A lot of my work sits where APIs meet AI agents: building **Model Context Protocol (MCP)** connectors that let language models call real software.

I care most about the things you only notice when they're missing:

- 🧠 **How systems work under the hood:** queues, caches, indexes, replication and the trade-offs behind each one
- 🛡️ **Reliability at scale:** code that still works next year, not just in today's demo
- ✨ **Building things people use:** a strong DSA base is only useful once it turns into production code that matters

When I learn something properly, I write it down. That's the [Chronicle](#-the-chronicle).
